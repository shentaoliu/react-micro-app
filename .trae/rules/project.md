# 项目开发约定

- 默认用中文说明任务结果；代码命名沿用项目约定。
- 修改前读取相关代码和 Git 状态。保留已有的暂存、未暂存和未跟踪文件，不自动提交或回退。
- 按用户本轮范围工作：只要求分析、规划或审查时不编辑代码；已经要求实现时完成必要修改和验证，不重复请求例行确认。
- 主应用使用 React、TypeScript、Vite、Ant Design；相关子应用是独立项目，可能使用不同版本。以各自 package.json、锁文件和实际安装包为准，不混用版本 API。
- 优先复用现有组件、请求封装、Redux 和主题机制。保持现有代码风格，不顺手重构无关模块；不默认升级或引入依赖。
- 使用明确类型；外部输入先校验，不用大量 any、关闭类型检查或关闭微前端沙箱来绕过问题。
- 换肤沿用现有 SkinProvider、Ant Design token 和 CSS 变量。涉及跨应用配置时检查现有 platformTheme 协议，不传递 React Context、组件实例或算法函数。
- 跨项目任务先定位并读取子应用；不能访问时指出缺失上下文，不编造文件、接口或运行结果。
- 按修改范围运行已有构建、lint 或相关检查；不假设每个项目都有相同脚本。不要把 Webpack/Babel 打包成功当作完整 TypeScript 检查。
- 交付时说明修改、验证结果和未验证项。区分代码检查、工具实测、用户报告；构建成功不代表浏览器验收成功。
